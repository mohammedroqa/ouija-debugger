# Seance UI style
- Mood: candlelit seance table. Dark parchment background (#14100c), aged-gold accents (#c9a24b), ghost-green glow (#7dffb2) for "spirit" text.
- Typography: serif display (e.g. "IM Fell English" via Google Fonts) with a monospace fallback for raw logs.
- Board: letters A-Z, digits 0-9, YES / NO / GOODBYE. A planchette moves smoothly to each letter as the diagnosis "spells out".
- Motion: slow easing, subtle flicker; respect `prefers-reduced-motion` (skip animation, show text immediately).
- Accessibility: the diagnosis must also appear as plain readable text; keyboard operable; contrast AA for body text.
- Keep it functional first: summon button, incident list, diagnosis panel.
